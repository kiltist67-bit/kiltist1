# Килтсит — файлы проекта

В корне проекта должны лежать:
- `server.js`
- `index.html`
- `package.json`

## Запуск
Node.js 18 или новее:
```bash
npm start
```
Затем откройте `http://localhost:3000`.

## Render
Создайте Web Service и подключите GitHub-репозиторий, в корне которого лежат эти три файла.
- Build Command: `npm install`
- Start Command: `npm start`

Для постоянного хранения данных настройте Persistent Disk и переменную `DATA_DIR` на путь монтирования диска.

## ВАЖНО — не публикуйте как настоящий мессенджер
Это демонстрационная версия. API пока не проверяет авторизацию и права доступа к данным.
Посторонние могут получить доступ к данным аккаунтов и переписок. Не используйте реальные пароли,
личные данные или настоящие переписки до полноценной доработки серверной безопасности.
